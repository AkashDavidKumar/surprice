**Surprice** is a high-fidelity, interactive April Fool prank designed to mimic a professional "hacker" intrusion. It combines a suspenseful terminal sequence with realistic digital corruption effects to give your target a brief (but safe!) scare.

## ✨ Features

- **Realistic Hacker Aesthetics**: Deep black terminal, neon green typography, and CRT scanline overlays.
- **Advanced Glitch System**: 
  - **RGB Chromatic Aberration**: Red/Cyan color shifting on key elements.
  - **Horizontal Tearing**: Sliced `clip-path` animations for that "corrupted" look.
  - **Screen-wide Bursts**: Inverted colors and random screen shakes to max out the tension.
- **Dynamic Terminal Logic**: Real-time progress bars, "system scanning," and simulated "private file uploading."
- **Audio Integration**: Syncronized digital beeps and "system wipe" alerts using Web Audio API.
- **Educational Reveal**: A friendly reveal modal that explains the origins of April Fools' Day.
